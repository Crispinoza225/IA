Comment fonctionne un navigateur ?

Quand tu tapes une adresse, ton navigateur enchaîne cinq étapes. Toile fait exactement la même chose, en beaucoup plus simple.

1. Le réseau

Le navigateur ouvre une connexion avec le serveur (chiffrée avec TLS pour https) et lui envoie une requête HTTP : GET /page HTTP/1.1. Le serveur répond avec un code (200 = tout va bien, 404 = introuvable), des en-têtes, puis le HTML.

2. L'arbre HTML

Le texte HTML est découpé en balises, puis rangé dans un arbre : le DOM. Chaque balise a des enfants. Les erreurs courantes (balises oubliées) sont corrigées au passage.

3. Les styles

Chaque règle CSS est comparée à chaque élément. Quand plusieurs règles se contredisent, la plus spécifique gagne. Certaines propriétés, comme la couleur, passent des parents aux enfants.

4. La mise en page

On calcule la position et la taille de chaque boîte : les blocs s'empilent, les mots se rangent en lignes.

5. Le dessin

Enfin, on peint les fonds, les bordures et le texte, de l'arrière vers l'avant.
