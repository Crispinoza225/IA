Toile

Un navigateur web écrit à partir de zéro, en Python

Pour commencer

  • La page de démonstration : titres, listes, couleurs, bordures, formulaires…
  • Comment fonctionne un navigateur ?
  • Tape une adresse en haut, par exemple https://example.com ou https://info.cern.ch.

Raccourcis

  • Molette ou flèches : faire défiler la page
  • Entrée dans la barre d'adresse : charger la page
  • Alt + ← et Alt + → : page précédente et suivante
  • F5 : recharger

Toile ne sait pas exécuter JavaScript : les sites modernes s'afficheront de façon simplifiée.
